Pattern 01

Divide & Conquer

Break a complex, high-entropy prompt into small, independent subtasks. Instead of demanding one monolithic LLM solve an entire problem in a single pass, isolate the logic.

CORE PRINCIPLE: Complexity is easier to control, debug, and model accurately when isolated into smaller units.
1 Decompose: Structure the complex prompt into distinct mini-prompts.
2 Solve Independently: Run subtasks in parallel or sequential isolated steps.
3 Aggregate: Combine deterministic schemas into the final output.

Pattern 02

Enrichment, Not Replacement

Use new information to selectively update or expand an existing result rather than regenerating everything from scratch.

CORE PRINCIPLE: Incremental improvement preserves state, avoids context collapse, and reduces latency compared to full rewrites.
1 Preserve Output: Lock verified output fields (e.g., base code structure).
2 Inject Context: Retrieve search results, user context, or dynamic tools.
3 Delta Update: Append missing details without disturbing verified content.

Pattern 03

Reflection Loop

Introduce an explicit verification step before accepting an output. Separate the generation model from the evaluation model to catch hallucinations and logic bugs.

CORE PRINCIPLE: Separate generation from verification. AI self-evaluates outputs against explicit rules before releasing.
1 Generate: Produce an initial draft response.
2 Reflect: Critic agent inspects output for errors, missed edge cases, or format flaws.
3 Correct or Accept: If issues are found, re-route to generator with feedback. Repeat until valid.

Pattern 04

Branch → Resolve → Merge

Keep the primary workflow thread running safely while isolating uncertain subproblems or long-running debugging steps into temporary sub-agent branches.

KEY IDEA: Don't block or crash the main agent pipeline. Fork the problem, fix and validate in isolation, and merge back clean context.
1 Branch: Fork state when encountering an ambiguity, error, or mini-task.
2 Resolve: Mini-agent resolves the isolated issue without corrupting main memory.
3 Merge & Continue: Integrate only the verified fix and continue primary execution.

The Pattern Matrix

A concise architectural comparison of the 4 core mechanisms for building predictable AI systems.

Pattern Purpose Core Mechanism When To Use
Divide & Conquer Control complexity Split a large task into smaller, independent subtasks → Aggregate Multi-step document processing, long code synthesis, multi-variable analysis
Enrichment, Not Replacement Preserve stability Improve existing state with new context without full regeneration Live search integration, updating structured JSON schemas, draft refinement
Reflection Catch errors & hallucinations Generate → Inspect via critic model → Correct before finalizing Code syntax checks, compliance validation, mathematical reasoning
Branch → Resolve → Merge Isolate failures Fork main thread → solve sub-problem in isolation → merge validated fix Long-running autonomous agents, bug fix loops, optional tool discovery
Unifying Philosophy

"Decompose complexity, preserve useful state, verify continuously, and isolate problems without disrupting the main workflow."
